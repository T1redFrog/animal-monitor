# Мониторинг бездомных животных во дворах
### Практика СИИ, вариант 9 — МТУСИ БИС2251-53

## Стек
- **YOLOv8n** (ultralytics) — предобученная модель детекции, классы: кошка, собака
- **Flask** — веб-сервер
- **OpenCV** — обработка изображений и видео
- **openpyxl + reportlab** — генерация Excel и PDF отчётов

## Структура проекта
```
animal_monitor/
├── app.py              # Flask-приложение, маршруты
├── detector.py         # Обёртка над YOLOv8
├── history.py          # Менеджер истории (JSON)
├── report.py           # Генерация Excel/PDF отчётов
├── requirements.txt
├── templates/
│   └── index.html      # Веб-интерфейс
├── static/
│   ├── uploads/        # Загруженные файлы
│   └── results/        # Результаты с аннотациями
└── history.json        # История запросов
```

## Установка и запуск

```bash
# 1. Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
python app.py
```

Открыть в браузере: http://localhost:5000

## Функционал
- Загрузка изображения или видео (drag & drop или клик)
- Детекция кошек и собак с bounding box и confidence score
- Статистика по результатам (кошек / собак / всего)
- История всех запросов в таблице
- Выгрузка отчёта в Excel и PDF

## Модель
YOLOv8n обучена на датасете COCO (80 классов).
Используемые классы: `cat` (ID 15), `dog` (ID 16).
Порог уверенности по умолчанию: 0.4.
Веса скачиваются автоматически при первом запуске (~6 МБ).
